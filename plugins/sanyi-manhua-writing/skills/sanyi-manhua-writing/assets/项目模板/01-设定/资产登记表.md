# 资产登记表（场景 / 角色造型）

> 用途：AI 视频生成的**一致性索引**。本表不限制你能写什么，只保证"同一个东西永远叫同一个名字"。
> 规则只有两条：
> 1. **新场景 / 新造型 = 新资产**：首次写入剧本前，先在本表登记，拿到编号。
> 2. **老资产 = 原样引用**：剧本中引用已有编号与名称，一字不改，不重新描述。

## 场景表

| 编号 | 名称 | 环境锚点（一句话，生成时作为参考描述） | 首用集数 | 备注 |
|---|---|---|---|---|
| S01 |  |  | EP |  |
| S02 |  |  | EP |  |

- 编号规则：`S` + 两位序号，按登记顺序递增，作废不回收（避免引用错位）。
- 环境锚点写**生成时需要稳定复现的要素**（装修风格、标志性陈设、色调），不写剧情信息。
- 同一场景的不同时间状态（日/夜）不算新资产，在场头标注即可；**重大陈设变化**（如火灾后废墟版）算新资产，登记为新编号并备注"基于 Sxx"。

## 角色造型表

| 角色 | 版本 | 形象锚点串（固定写法、固定顺序） | 首用集数 | 备注 |
|---|---|---|---|---|
|  | V1 |  | EP |  |
|  | V2 |  | EP |  |

- 形象锚点串 = 生成时锁死一致性的关键词组合（发型 / 服装 / 标志性配饰），**写法与顺序固定**，任何一集引用时不增删、不调序。
- 默认造型为 V1。换装、受伤、年龄变化等 = 新增版本（V2、V3…），在档案登记后剧本才能使用。
- 剧本正文**只写角色名，不重复描述外貌**；需要非默认造型时在场头或动作行标注版本，如"林晚（V2-病号服）"。
- 角色的性格、声音、关系设定在 `角色档案.md`，本表只管"脸和衣服"。

## 维护时机

- 写分集大纲时：预登记主线场景与主角 V1 造型。
- 每集收尾流程中：把本集新增的场景 / 造型补登进本表（见本 skill 的收尾流程）。
