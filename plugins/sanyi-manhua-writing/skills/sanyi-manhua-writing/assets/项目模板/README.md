# 项目模板 V2.2 · 使用说明

> 本模板是"写作线 V2.2"的项目级工作区，与 `sanyi-manhua-writing` skill 配套使用。
> V2.2 变更：补回 V2.1 简化时遗漏的三项长线工具（人物弧光与行动卡、世界观释放与悬疑分层、双轨节奏与错位场景），均以**可选参考层**形式加入，不进硬五条，日常单集写作不受影响。新增 `03-大纲/弧光预算表.md`、`02-状态/悬疑信号表.md`（可选），角色档案、世界观与铁律、分集大纲、剧本模板加入对应指针字段。

1. 把整个文件夹复制为你的项目目录，`AGENTS.md` 和 `CLAUDE.md` 都放在根目录。`AGENTS.md` 是正本（Codex、Kimi Code 读取）；`CLAUDE.md` 只有一行 `@AGENTS.md`，供 Claude Code 导入，不要单独修改。
2. 填 `AGENTS.md` 顶部"项目一句话"；项目专属规则（对白风格、禁用套话）补在"项目专属规则"下。
3. 在 `01-设定/资产登记表.md` 预登记主线场景和主角 V1 造型；之后新资产随写随登。
4. 填好 `01-设定` 各文件与 `03-大纲/分集大纲.md`（含每集主情绪事件、主导基调），再开始写第 1 集。
   - 长线项目/开新季：额外填 `03-大纲/弧光预算表.md`。
   - 世界观有"表层之下还有东西"：填 `01-设定/世界观与铁律.md` 的世界观释放表。
   - 悬疑/推理/身份秘密类子题材：创建并维护 `02-状态/悬疑信号表.md`；不需要就删掉这份文件。
5. 每集一个新会话；开场说："用 sanyi-manhua-writing skill，读本目录 AGENTS.md，按开工流程写 EPxx"。
6. 每集写完，按收尾流程填单集开发卡并更新 `02-状态` 各文件，你自己快速扫一眼。
7. 有平台数据后，记入 `02-状态/留存复盘.md`，回头校准参考层的节奏标准；如果发现连续几集流失明显，先查这几集的"主导基调"是否重复（见 `references/双轨节奏与错位场景.md`）。
8. 分镜/制片交付不属于写作线，转独立的生产交付线处理。
9. 评分、评审不属于写作线，在独立会话按独立评审规则进行。

## 目录
```
AGENTS.md（正本）  CLAUDE.md（仅导入 AGENTS.md）
01-设定/   角色档案.md（含行动卡）  世界观与铁律.md（含释放表）  资产登记表.md
02-状态/   剧情摘要.md  人物状态表.md  伏笔清单.md  下集简报.md  留存复盘.md  悬疑信号表.md（可选）
03-大纲/   分集大纲.md  弧光预算表.md（可选）
04-剧本/   _模板.md  EP01.md ...
```

## 哪些是"可选"，哪些不是

日常单集写作只需要：`AGENTS.md`（及导入它的 `CLAUDE.md`）+ `01-设定/角色档案.md` + `01-设定/世界观与铁律.md`（不含释放表也没关系）+ `01-设定/资产登记表.md` + `03-大纲/分集大纲.md`（不含弧光预算/悬疑信号）+ `02-状态/` 五份常规表 + `04-剧本/_模板.md`。

`弧光预算表.md` 和 `悬疑信号表.md` 是否需要，取决于项目本身：短平快、人物不打算做长线转变、题材不涉及悬疑身份秘密的项目，可以直接不建这两份文件，不影响其余流程运行。
