# 人物弧光与行动卡（参考层）

> 用途：立项写人设、新开一季、角色即将做关键选择或转折时查阅。
> 只用于主角与核心常驻角色；一次性客人不套用本文件，参考 `人物魅力法则.md` 的"配角：一个记忆点"即可。
> 本文件讲**怎么把人物写得前后一致、有据可查**；魅力从哪来、关系怎么设计，见 `人物魅力法则.md`。两份文件配合用，不重复。

## 一、人物行动卡（字段表）

新角色定稿、或角色发生重大变化后维护，写进 `01-设定/角色档案.md` 对应人物小节下方：

| 字段 | 要求 |
|---|---|
| 外在需求（Want） | 角色自己知道、会主动追逐的具体目标。 |
| 内在缺口（Need） | 角色未必意识到、却会在关键选择中反复卡住的深层需要。只用于创作判断，不写成心理诊断。 |
| Want／Need 的张力 | 一句话：这两者哪里拧着——这是弧光真正会发生的地方。 |
| 前史根源 | 只保留能解释 Want、Need 或矛盾从何而来的关键事件；不是履历堆砌。 |
| 外显矛盾 | 口头姿态/习惯与真实需要之间可拍的反差。 |
| 不可替代能力 | 这件事为什么必须由她参与，换人不行。 |
| 关系债与底线 | 欠谁、护谁、害怕失去谁、拒绝拿什么交换。 |
| 说话与动作习惯 | 压力下、撒谎时、得意时、受伤时，分别会怎样说和做。 |

一次性角色不套用本表；群像中每位常驻角色至少要能在表里写出"不可替代能力"和"关系债"两项，写不出说明这个角色目前是工具人。

## 二、弧光预算（季度/长线项目使用）

新一季或重大重规划时，为主角与核心常驻角色各列一份：

`A 状态 → B 状态`（起点处境／信念 → 终点处境／信念，不可逆）

- **前 25% 集数**：只建立问题和微弱变化，不提前让角色转变。
- **中段**：允许"看似改变 → 回退／伪变化"，制造反复，但每一步都要在行动和关系后果中可见。
- **危机之后**：才允许关键转变（从 A 状态真正跨到 B 状态）。
- **单集不要求人人变化。** 弧光预算检查的是角色结尾的物理状态、关系状态、已知信息、下一集待回应点是否可追踪，不是要求每集都有成长。

弧光预算写在 `03-大纲/弧光预算表.md`，只在立项、开新季或大改大纲时整体过一遍；日常单集写作不需要重新填。

## 三、和其他文件的分工

- **角色档案.md**：写人物的稳定设定（身份、欲望、说话方式），加上本文件第一节的行动卡字段。设定阶段一次写好，很少改。
- **人物状态表.md**（02-状态）：写人物**此刻**的处境、关系、秘密，每集收尾更新，属于会变的状态，不属于本文件管的"稳定设定"。
- **弧光预算表.md**（03-大纲）：写整季/长线的成长曲线规划，只在立项或改季时整体过一遍。
- **人物魅力法则.md**：讲原则和自查清单（为什么这样设计会有魅力）；本文件讲结构（怎么把设计记下来、怎么保证前后一致）。

## 四、使用时机

- 新角色定稿时：填一次行动卡。
- 新一季/重大重规划时：填一次弧光预算。
- 角色做出关键选择、或某场戏感觉"这个角色怎么这样"时：翻出行动卡对照，看是否符合 Want／Need 的张力，而不是临时现编动机。
- 日常单集写作：不需要每集重填，只在单集开发卡的"状态变化"里记录本集是否触发了微变、回退或关键转变之一。
