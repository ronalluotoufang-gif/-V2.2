# 人物魅力法则（参考层）

> 用途：立项写人设、写对手戏、或角色感觉"没魅力"时查阅。
> 人物规则的唯一参考文件：原散落在角色档案、题材合同、台词文件中的角色要求，以本文件为总索引。
> 本文件只讲怎么写，不含任何评分规则。

## 一、魅力四来源（主角与常驻角色）

1. **主动欲望**：角色此刻想要什么，并且自己动手去拿。被剧情推着走的角色没有魅力。
2. **可识别缺口**：角色在关键选择中反复卡住的那个点。前史只保留解释"他为什么卡"的关键事件，不是履历堆砌。
3. **外显反差**：嘴上姿态与真实需要之间可拍的反差（嘴硬心软、精致利己者偷偷守护）。
4. **不可替代性**：这件事为什么必须由他做——独有能力、独有信息、独有关系，至少占一。

四者缺一，角色立不住；四者俱全但**选择不用付出代价**，魅力减半——魅力在选择和代价中显形，不在设定里。

## 二、三类角色的魅力公式

### 主角：选择 + 代价

- 每个阶段至少一次两难选择并承担代价；关键结果必须由他的判断、选择或承担换来，不能长期只接收别人替他完成的答案。
- 弧光允许"看似改变 → 回退/伪变化 → 关键选择"的渐进过程，但每一步必须在行动和关系后果中可见；单集不强迫变化。

### 反派/对手：价值观 + 持续压迫力

- 反派要有一套自洽的价值观（他认为自己是对的），有资源、有行动方式。
- 压迫分层升级：轻视 → 羞辱 → 剥夺 → 围猎 → 公开碾压，不一直用同一种压迫。
- 反派不降智：输给主角的准备与选择，不输给自己的愚蠢。

### 配角：一个记忆点

- 标志性动作 / 口癖 / 随身物件，**三选一**，多了是堆砌。
- 常驻配角每集至少承担行动、关系后果或价值选择之一；不做递线索、解题、卖萌的工具人。
- 一次性角色不套用深度框架，有一个功能加一个反差即可。

## 三、关系张力设计

- 每段核心关系至少埋一根"刺"：利益绑定、情感债、秘密、价值冲突，四选一以上。
- 对手戏里让角色对"先救谁、信谁、拿什么交换、承担谁的风险"有真实分歧——这是关系戏，不是轮流说功能说明。
- 关系变化落在可见事件上（站队、决裂、守护、背叛），不靠台词宣布"我们关系变了"。

## 四、出场设计

新角色首次出场同时带四样：**欲望、能力、短板、与主角的立场差**。不写"一次委托后立即正式入职"式速熟。

## 五、口吻辨识度

- 用词、句长、停顿、称呼、回避方式能区分角色，而不是只在名字前后替换。
- 角色在压力下、撒谎时、得意时、受伤时各有稳定反应模式，写进角色档案的"说话与动作习惯"。
- 口头禅可以有一个，但口头禅不替代人物行为。

## 六、自查清单（写完人设或关键场次后过一遍）

- [ ] 主角本集有主动目标，并为选择付出了代价？
- [ ] 删掉角色名，只看台词和动作，能分出谁是谁？
- [ ] 反派的每一步都有他的道理和资源支撑？
- [ ] 核心关系的"刺"本集是否被碰到？
- [ ] 配角是否只是递线索/解题/卖萌？
- [ ] 新角色出场是否欲望、能力、短板、立场差四样齐全？
