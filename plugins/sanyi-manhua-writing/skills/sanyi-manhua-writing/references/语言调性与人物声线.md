# 语言调性与人物声线（参考层）

> 用途：立项或开新季时填《语言调性卡》、定人物声线；每集开工读调性卡与出场人物的声线；每集写完做声口自检。核心规则 H4"声口对位"的执行细则。
> 本文件只讲怎么写、怎么查，不含任何评分规则。

## 一、三层结构＋一个开关

| 层 | 管什么 | 写在哪 | 稳定性 |
|---|---|---|---|
| 全剧调性 | 整部剧台词的底色：时代感、文白或书面程度、句长倾向、梗的边界 | `01-设定/语言调性卡.md` 第一、二节 | 全剧不变 |
| 身份语域 | 同一身份、阶层、阵营、种族、职业共享的说法：称谓、切换语多少、句式 | 调性卡第四节 | 全剧不变；新身份出场前补一行 |
| 个人声线 | 同一语域里区分个人：句长、专属标志、称呼、回避方式、四态 | `01-设定/角色档案.md` 每人的"声线" | 人设定稿后很少改；称呼可随关系变 |
| 场合开关 | 同一个人在特定场合换说法（文白、术语与俚语、公开与私下） | 调性卡第五节＋声线的"公开／私下" | 按场合触发 |

- 下层建在上层之上：先像这个世界，再像这个身份，最后像这个人。
- 个人可以偏离所属语域，但偏离要写理由。偏离常是反差和笑点的来源，比如草莽出身的将军进了朝堂，现代人穿越进了宫廷。
- **与"本集主导基调"区分**：分集大纲里的主导基调（悬疑紧张、轻快转温情）是情绪，每集可变；语言调性是说话的质感，全剧不变。情绪变了，底色不变：悬疑集里的宋代士大夫，说的仍是宋代士大夫的话。

## 二、冲突时的取舍顺序

1. 台词要干活（H4 五项功能）；
2. 观众第一次听就要懂大意；
3. 不出戏：禁用表是红线，只有声线里写明理由的偏离可以破例；
4. 像这个人（个人声线）；
5. 像这个身份（身份语域）。

- 考据服务于"不出戏"，不服务于学术正确。观众觉得"像那个时代、那个世界"就够了；先排除明显的错位（例如清宫腔进了宋代），不为冷僻考据牺牲可懂性。
- 称谓、官职、机构、器物属于事实，未核实的按事实纪律标【待核验】。

## 三、《语言调性卡》填法

立项或开新季时填，之后很少改，改动要用户确认。模板见 `assets/项目模板/01-设定/语言调性卡.md`。

1. **调性定位**：一句话说清"这部剧的人怎么说话"，可附一部语感参照作品（只取语感，不搬台词）。
2. **底色**：口语还是书面、文白比例、句子偏长还是偏短、常用语气词。
3. **用词池**：这个世界的器物、货币、时间、职务、俚语怎么说。
4. **出戏词禁用表**，分三类，每条附替换说法，写作时直接换：
   - 现代词：古装剧里的"压力、搞定、OK"；
   - 时代或世界错位词：别的朝代、别的世界观的词，如宋代剧里出现清宫腔"嗻、奴才、皇阿玛"，或明代机构"锦衣卫、东厂"；
   - 题材错位腔：别的题材的套话串进来，如霸总腔进古装、宫斗腔进武侠、播音腔进日常。
5. **称谓体系**：自称、称对方、背后称呼，按身份和亲疏分。称呼的变化是可见的关系事件，不能随手换。
6. **梗与外来词边界**：网络梗、英文、谐音梗、二次元用语能不能用、谁能用、一集用多少。
7. **专有名词的日常说法**：设定名词第一次出现在台词里时怎么说，让观众一听就懂（如先说"能续命的药丸"，不一上来就说"九转还魂丹"）。一句话里不堆两个以上新名词。
8. **身份语域表**：见第四节。
9. **场合切换规则**：见第五节。
10. **跨世界碰撞规则**（混搭题材必填）：两套说法在同一场相遇时，谁听不懂谁、谁会学谁的话、误会怎么产生、笑点之后有什么剧情后果。
11. **校准样句**：对的 3 句、出戏的 3 句（注明出戏在哪）。新会话开写前读一遍，比读规则更快对齐手感。

## 四、身份语域表

按身份、阶层、阵营、种族、职业划分，不按单个人物。

| 栏目 | 写什么 |
|---|---|
| 身份 | 如皇帝、士大夫、武将、贵女、仆役；或军方、平民、AI；或异界族群、现代人 |
| 自称与称呼 | 对上、对平辈、对下各怎么称 |
| 切换语多少 | 文言、术语、异界说法在这个身份口中的浓度 |
| 何时切换 | 这个身份在哪些场合会换说法 |
| 句式特征 | 句长、爱不爱引经据典、爱不爱用命令句、说话绕不绕 |
| 雷区 | 这个身份不该有的说法；越界要有剧情理由 |

- 一个人物主属一个语域。身份跨界的人物（出身草莽的将军、落难贵女、混进人类社会的妖族）写"主语域＋残留"。残留在压力下最容易冒出来，可以用作破绽或笑点。
- 一次性角色只需归入某个语域，再给一个专属标志。

## 五、场合切换（触发式语域切换）

同一个人在特定场合换一套说法。题材不同，切换语不同：

| 题材 | 底色 | 切换语 | 典型触发 |
|---|---|---|---|
| 古装/古风 | 浅近白话 | 文言 | 讲大义、礼仪场面、朝堂奏对、诏书书信、引经据典、对峙时摆身份 |
| 科幻/未来 | 未来日常口语 | 军方、技术术语 | 作战、汇报、危机处置 |
| 职场/都市 | 现代口语 | 汇报腔、行话 | 开会、对上级、谈判 |
| 异界/穿越混搭 | 现代口语 | 异界说法、本族规矩用语 | 发誓、讲本族规矩、情绪失控 |
| 无厘头/轻喜剧 | 现代口语 | 一本正经的庄重腔 | 用庄重腔讲小事，制造反差 |

**用量规则**
- 一次一到两句，优先用成句、四字格、引语、誓词，不写整段；
- 马上接住：紧跟一句白话、一个动作或一个可见结果，让观众第一次听就懂大意；
- 同一场里连续的切换语不超过 3 句；宣旨、祭文、军令、书信这类"照稿念"的场面可以长，但画面要同时交代结果；
- 切换语不承担唯一的关键信息：主线目标、规则、因果结果必须用底色说法或画面给到。

**让切换干活**：切换本身就是戏，每次切换至少承担 H4 的一项功能；纯装饰的文言、术语删掉。
- 底色 → 切换语：拉开距离、摆身份、动真怒、表明立场、用规矩反击；
- 切换语 → 底色：卸下身份、示好亲近、破防、说真话。

例（示意，项目可替换）：贵女平日和丫鬟说白话，被当众逼婚时换一句讲礼法的成句顶回去，下一句用白话把话挑明，观众听得出她在用规矩反击。皇帝在朝堂上满口"朕"，退朝后对老臣说一句大白话，两人的关系当场显形。

## 六、个人声线（写进角色档案）

| 字段 | 写什么 |
|---|---|
| 所属语域／偏离 | 属于哪个身份语域；哪里偏离，为什么偏离 |
| 句长与节奏 | 利落短句、绕弯长句、爱停顿、爱抢话…… |
| 专属标志 | 标点（省略号、破折号）、重复词、结巴、口头禅、自称。**一种标志只给一个人**，别人不用 |
| 称呼表 | 对谁叫什么；关系变化时称呼怎么变 |
| 公开／私下 | 两种场合各怎么说；没有差别就写"一致" |
| 四态 | 压力下、撒谎时、得意时、受伤时各怎么说 |
| 绝不会说的话 | 说了就崩人设的词和腔 |
| 对白示例 | 2~3 句，用于校准声音 |

- 主角与核心常驻角色全填；常驻配角至少填语域、专属标志、称呼表、四态；一次性角色只填语域和一个专属标志。
- 口头禅最多一个，不替代人物行为（见《人物魅力法则》第五节）。
- 角色档案末尾维护一张"声线对照表"（人物｜所属语域｜专属标志｜情绪如何露出），做删名测试时直接对照。

## 七、使用时机

- **立项或开新季**：先填调性卡（含身份语域表、场合切换规则），再写人设；每个人的声线都对照调性卡，定下是贴合还是偏离。
- **每集开工**：读调性卡，再读本集出场人物的声线（只读出场的人）。本集有关键的切换场面（讲大义、发誓、两个世界的人碰面）时，在写作思路里用一句点出。
- **新身份、种族、阵营的角色出场前**：先在身份语域表补一行，用户确认后再写。
- **每集写完**：做第八节声口自检，结论填进开发卡"自检"栏的 H4。
- 项目还没有调性卡时，先向用户确认调性，不擅自定调。单集写作中发现调性卡缺项，标【待核验】，在收尾第 5 步列给用户。

## 八、声口自检（每集写完必做）

1. **出戏词扫描**：逐句对照禁用表三类（现代词／时代或世界错位词／题材错位腔），命中就换成表里的替换说法。
2. **删名测试**：盖住角色名只看台词，能不能分出是谁在说。分不出时，按声线改句长、称呼、专属标志、回避方式；不靠多加口头禅。
3. **身份越界**：说法与所属语域不符、声线里又没写偏离理由的，改。
4. **切换可懂性**：每处切换语，观众第一次听能不能懂大意，或者下一句、画面有没有接住；它承担了 H4 的哪一项功能。
5. **称谓一致**：同一关系的称呼前后一致；变了的，必须对应一个可见的关系事件。

开发卡里只写结论，例如 `H4 声口：通过`，或 `H4 声口：问题（场 3，仆役讲大义，身份越界）→ 修法`。

## 九、调性速查（立项选调性时参考，不替代项目调性卡）

| 调性 | 底色特征 | 常见出戏 | 常见翻车 |
|---|---|---|---|
| 古风/古装 | 浅近白话为底，文言点缀 | 现代词；后世朝代词 | 通篇文言，观众听不懂；清宫腔串台；人人引经据典 |
| 武侠/江湖 | 白话＋江湖说法 | 官场腔、现代词 | 全员说书人腔 |
| 科幻/未来 | 现代口语微调＋少量新词 | 设定里没保留的当下器物与梗 | 术语堆叠；为显得"未来"，人人说报告腔 |
| 现代都市 | 当下口语 | 书面腔、翻译腔、过时网络梗 | 全员金句；霸总腔串台 |
| 无厘头/轻喜剧 | 现代口语＋一本正经的反差 | 没有因果的梗 | 靠梗堆笑点；人人抖机灵，没有"正常人"做反衬 |
| 日漫二次元 | 现代口语＋角色化的自称与口癖 | 直译日语腔堆叠 | 全员卖萌；口癖替代行为 |

## 十、填写示例：宋代官宦（古风样板）

> 示意项目，只演示怎么填。称谓按项目选定的参考资料核实后才算数。

- 调性定位：宋代官宦世家往来，浅近白话为底，讲大义、礼仪时点一两句文言。
- 底色：读得懂的古典小说对白；不是现代口语，也不是通篇文言。
- 出戏词：现代词（压力、搞定、OK）；后世词（嗻、奴才、皇阿玛、锦衣卫、东厂）。

| 身份 | 自称与称呼（示例，需考据） | 文言多少 | 何时用文言 | 句式特征 | 雷区 |
|---|---|---|---|---|---|
| 皇帝 | 正式场合"朕"，私下可称"我"；被称"官家" | 看场合 | 朝堂、诏令、表态 | 私下可以很白；一换文言就是在摆君威 | 私下也满口"朕"，没有松弛的时候 |
| 士大夫 | 自称"某""臣"；互称字号、官职 | 最多 | 论政、讲礼、劝谏、书信 | 爱引经据典，骂人也引经 | 粗口、江湖话 |
| 武将 | 对君称"臣" | 少 | 立誓、请战、讲忠义 | 短句、直；偶尔冒一句兵书，是粗中有细的反差 | 通篇文绉绉 |
| 贵女 | 自称"奴""奴家"；被称"娘子""小娘子" | 中等 | 讲礼法、当众应对 | 闺中说白话，人前守礼 | 用"小姐"称呼大家闺秀（宋代"小姐"不是这个意思） |
| 仆役 | 称主人"郎君""娘子" | 几乎没有 | 原则上不用 | 短、实在、带市井气 | 无缘无故讲大义 |
