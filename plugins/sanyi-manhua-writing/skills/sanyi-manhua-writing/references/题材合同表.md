# 题材合同表（参考层）

> 用途：立项、改题材、或某集"不像这个题材"时查阅。
> 题材模板是**观看合同**，不是灵感库。立项时选定一个主题材 + 至多两个子题材，写一页合同：
> `核心观看期待｜必须持续兑现｜常用但非必需结构｜节奏红线｜不可替代视觉/关系资源`。

## 调用纪律

1. 主题材决定最高优先级观看期待；子题材只能增强，不得夺走核心承诺。
2. 每集至少服务主题材的一项"必须持续兑现"；日常/呼吸集也可兑现关系、经营、成长或规则理解，不能无目标闲聊。
3. 使用"常用结构"前先问：它是否改变人物选择、关系、资源、风险或阶段方法；不能就不加。
4. 模板不覆盖项目已确认事实：修仙项目不必然有宗门，恋爱项目不必然有误会，升级项目不必然数值化。
5. 跨题材只保留一个主导观看期待 + 一至两个辅助期待；两类元素不能在同一场戏里互相制造行动与后果的，是拼贴，不是创新。

## 题材合同表

| 题材/子题材 | 必须持续兑现 | 常用但非必需结构 | 节奏红线 |
|---|---|---|---|
| 升级流/成长流 | 成长有可见梯度；每次突破改变能做什么、面对谁、付什么代价 | 天赋觉醒、任务奖励、越阶挑战、阶段榜单 | 不把换数字、换敌人、换地图当成长；能力不能万能 |
| 修仙/玄幻成长 | 力量层级、资源、能力边界与身份处境互相影响 | 秘境、法器、师徒、宗门大比 | 不以境界名词替代训练、代价和成果；战力不随剧情伸缩 |
| 宗门修仙/仙门群像 | 宗门、师承、阵营秩序真实影响资源、站队与冲突 | 入门考核、门派任务、师门竞争 | 散修/公路子题材不强套宗门，但须有社会秩序与资源来源 |
| 女频情感/女性成长 | 被看见、被选择、自我价值、关系边界或成长回报持续发生 | 误会、救赎、身份差、情敌、共同困境 | 不把受苦、牺牲、被追求本身当情绪价值；角色必须主动 |
| 恋爱/甜宠/奇幻言情 | 注意 → 特殊对待 → 拉扯/共同选择 → 关系阶段变化；彼此能改变行动 | 暧昧误会、吃醋、契约、禁忌身份 | 不重复撒糖；不用误会、宿命、亲密动作替代关系推进 |
| 关系悬疑/女频悬疑 | 关系变化成为线索；物证、人证、情绪反应相互校验；真相可回看 | 隐瞒、信任反复、双视角误导 | 不只谈感情不推进调查；反转不牺牲公平线索 |
| 悬疑灵异/异界规则 | 规则可验证、有来源、可被有限利用；破局有代价 | 禁忌、委托、旧案、能力反噬 | 不堆诡异名词、不随意改规则、不无代价破局 |
| 规则怪谈/推理 | 观众看得见的线索、可利用的漏洞、能回溯的真相 | 身份反转、时序误导、规则试错 | 不藏关键证据、不临场补规则、不用谜题压垮理解 |
| 都市脑洞/日常异变 | 日常与异常形成反差；异常真实影响生活、关系、成本和知情层级 | 职业反差、日用品异化、隐秘组织 | 设定升级不能快过人物适应与行动 |
| 经营/种田/团队建设 | 资源、成本、积累与阶段成果可见，并反哺关系或主线 | 补货、口碑、复购、店铺改造 | 不把经营写成报表；收入成本扩张不凭空发生 |
| 逆袭/复仇/打脸 | 压迫具体可见；主角靠准备、选择与行动拿到改变地位的回报 | 身份揭示、当众反击、资源反转、旧账回收 | 不靠路人震惊、反派降智或偶然身份救场；不同规模重复 |
| 宅斗宫斗/豪门关系 | 权力、资源、名分、信息与关系位置决定代价 | 宴会、婚约、家族规矩、继承争夺 | 不靠降智误会拖戏；现代项目不照搬古装逻辑 |
| 民俗怪谈/恐怖 | 明确禁忌、具体后果、可感知威胁与受限破局 | 仪式、地方传说、禁地、代际秘密 | 不用无来源惊吓、血腥堆砌或结尾解释抹掉恐惧 |
| 沙雕脑洞/轻喜剧 | 反差来自人物目标、信息错位或严肃规则被日常方式解决；笑点有后果 | 误会、反向常识、可回收口癖 | 不靠降智、无因果冷笑话或网络梗堆叠 |
| 双男主/伙伴冒险 | 双核心各有不可替代目标、能力与立场；合作与分歧均改变结果 | 互补破局、互相试探、共同秘密 | 不把一人写万能主角，另一人只作工具或捧哏 |
